Ships over the air. Every value above is a plain JavaScript style prop or an already-installed dependency — reanimated 4.1.1 and react-native-worklets 0.5.1 are both present with newArchEnabled on. No build credits, no App Store review round, and rollback is republishing the previous update.
Two files stay hardcoded on purpose. app/_layout.tsx and UpdateCheckScreen.tsx pin brand navy to match the native splash; tokenizing them reintroduces a color flash before theme state hydrates. radar.tsx line 65 carries a Mapbox-native style prop that is not a React Native style — migration tooling must skip it, and that screen needs its own device check.
These frames render in the OS font, deliberately. Custom typefaces need expo-font, which is a native module and would force new binaries for both stores. The hierarchy above is built entirely from size, weight and tracking on the system stack — which is exactly what will render on a device.
